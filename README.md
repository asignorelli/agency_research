# agency_research
Research Project for Ai Ethics 1684

## Completed experiment

[PHA-2026-V3: study data and reproducible runner](experiments/PHA-2026-V3/README.md)
contains the completed 180-response experiment, frozen inputs, and provisional
automated grading records.

Independent human graders should start with the
[human grading kit](experiments/PHA-2026-V3/manual_grading/README.md), which includes
the full rubric, step-by-step instructions, practice cases, a blank worksheet, and
all 180 condition-blind responses. Complete independent ratings before inspecting
automated evaluations or condition mappings.

The easiest way to grade is the
[annotation website](https://asignorelli.github.io/agency_research/): a skippable
rubric tutorial and practice round, then one response at a time, with every answer
saved to a shared database as soon as you click Save. Setup and export instructions
are in [the site's README](experiments/PHA-2026-V3/annotation_site/README.md).
