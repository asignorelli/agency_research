# Practice before main human grading

The [18 practice cases](exercises_v1.0.md) are researcher-authored examples on
`largest_number`, `unique_letters`, and `format_receipt`. They are outside the
20 scored tasks and Tutor C's separate `count_positive` demonstration. These are
practice materials, not experimental tutor observations.

The original exercise text is preserved verbatim. Its references to
`evaluation_rubric_v1.0.md` mean the identical [rubric in this kit](../rubric_v1.0.md);
use the [schema in this kit](../evaluation_result.v1.0.schema.json). Historical
instructions to finish calibration before collection do not assert that this
happened. Main collection has already occurred under the protocol amendment.
Complete and date calibration **before your independent main human ratings**, and
disclose its actual timing.

Both graders should score all 18 cases independently using the
[blank worksheet](../grading_worksheet.md). Preserve the initial ratings. Only then
should a coordinator release the provisional key, held separately in
`published_data/researcher_only/calibration/`. Initial graders should not browse
that folder: its parent also contains actual experiment outcomes and conditions.
Keep practice worksheets separate. The packet checker is for the 180 main responses;
it does not import practice IDs into the experiment.

Discuss disagreements with the rubric, record decisions and exposure in the
[session log](session_log.md), and freeze instructions. The key includes an
intentionally disputed case and illustrative secondary scores; it is a calibration
aid, not an automatically binding replacement for the rubric. Do not add these
18 cases to the 180 experimental observations.
