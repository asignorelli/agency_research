# Coordinator-held practice key

The adjacent `answer_key_v1.0.md` is the original researcher-authored **provisional**
practice key, copied unchanged. It covers only 18 out-of-bank calibration examples;
these are not experimental tutor results. It contains an intentionally disputed
boundary and illustrative secondary scores.

Release this key to initial graders only after both have submitted their independent
practice ratings. Prefer giving them this one file rather than directing them to
browse the parent directory, which contains actual automated outcomes and condition
mappings. Record the release date and discussion in the calibration session log.
Use the approved rubric to resolve disagreements; preserve original ratings.
